How to use the ICO 2026 Dataset
===============================

This repository provides some examples on how to use the [Innovation Capabilities Outlook 2026 Dataset](https://tind.wipo.int/record/59177?ln=en&v=zip). 

The dataset provides access to the full underlying microdata, capturing global innovation dynamics across multiple dimensions, including outputs, capabilities, and complexity, spanning different innovation fields, geographic locations, and time periods. It is organized into eight parquet files that together describe innovation activity, specialization patterns, relationships between fields and places, and measures of innovation potential and sophistication. This dataset contains the underlying data used for the [Innovation Capabilities Outlook 2026 report](https://tind.wipo.int/record/59097?ln=en&v=pdf). 


See the [Innovation Capabilities Outlook 2026: Technical Notes](https://tind.wipo.int/record/59227?v=pdf) outlining the methodology, detailing data sources, clustering procedures, and economic complexity metrics used to evaluate scientific, technological, entrepreneurial, and industrial capabilities across countries.
